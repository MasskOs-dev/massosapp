About Quantum Browser

Quantum Browser is a desktop web browser built with Python, PySide6, Qt Quick, and QtWebEngine. Chromium renders web pages; QML provides the browser interface.

It was made to provide a straightforward browser that can restore ordinary tabs, keep private tabs separate, expose privacy settings, and use Qt's native WebEngine capabilities instead of a custom web renderer.

The JPEG logo used on this page is ../assets/logo.jpeg. The running application uses the PNG logo for its window and start page.

Quick start

Run from source

Use Python 3.12 or newer and install the dependencies declared by the project:

python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r Frontend/requirements.txt
python Frontend/main.py

Qt 6.9 or newer is required for the profile-prototype API used by the browser. On Linux, a working desktop session and QtWebEngine system libraries are also required.

Install a Debian package

If you have the locally built package, install it from the project directory with:

sudo apt install ./Frontend/dist/quantum-browser_0.1.0_amd64.deb

The package bundles QtWebEngine and is consequently large. Installing it requires administrator permission.

Using the browser

  • Search or navigate: type a search phrase or URL in the address field. Google is the initial search provider; change providers in Settings → General.
  • Open a normal tab: use the plus button or Ctrl+T.
  • Open a private tab: use the eye-off button or Ctrl+Shift+N.
  • Close a tab: use its close icon, middle-click it, or press Ctrl+W.
  • Move between tabs: use Ctrl+Tab.
  • Focus the address field: press Ctrl+L.
  • Navigate back/forward: use the toolbar buttons or Alt+Left/Alt+Right.
  • Manage saved pages: use the star for bookmarks, the clock for session history, and the download icon for downloads.

The address and title bar hide after 30 seconds without pointer movement. Move the pointer over the window to reveal them; the tab strip remains visible.

Privacy and safety

  • Session restore: ordinary open-tab URLs, titles, and selected-tab position are saved in the user's Qt settings. At most 20 tabs are retained.
  • Private tabs: they use an off-the-record profile with in-memory cookies and cache. Private tab URLs are excluded from session restore and the browser history list. When the last private tab closes, cookies, cache, and private download entries are cleared.
  • History: the browser's history panel is in-memory for the current run. It is separate from session restore.
  • Tracker blocking: the built-in domain list is enabled by default. It is not a full replacement for a maintained filter-list extension.
  • HTTPS upgrade: optional in Settings → Privacy. It is off by default so HTTP-only sites remain reachable.
  • Site permissions: requests for camera, microphone, location, notifications, and similar capabilities prompt for an explicit decision.
  • WebRTC: Settings → Security can restrict WebRTC to public interfaces, which reduces local IP exposure but may affect some calls.

Private mode limits data saved by this browser profile. It does not hide traffic from websites, search providers, network operators, or the internet service provider.

Video and certificates

Web pages use QtWebEngine's Chromium media stack. HTML5 media playback, autoplay, and fullscreen requests are enabled. Downloads are managed by the browser and saved to the system Downloads folder.

Video compatibility depends on codecs compiled into the installed QtWebEngine build. Some services require Widevine/DRM, which this application does not bundle or guarantee. A browser setting cannot add a missing codec or DRM module.

For an invalid TLS certificate, the browser rejects non-overridable failures. When Qt marks a certificate error as overridable, the browser shows a one-time Continue option. Only proceed if you trust the site and understand the risk; a certificate warning can indicate interception or a misconfigured server.

The Chromium net_error -202 commonly means the certificate authority is not trusted. The lasting fix is to correct the server certificate or install the legitimate CA certificate in the operating system's trust store, not to disable certificate checks globally.

Messages such as chat.init: chat button not found originate in the loaded website's JavaScript. They are not browser startup errors.

Extensions

Open Settings → Extensions to load a local Chromium .crx file or an unpacked extension directory, toggle extensions, or remove them. Direct Chrome Web Store installation is not implemented. Extensions receive the permissions declared by their manifests.

The built-in tracker blocker is enabled by default. AdGuard is not bundled; install it only from a trusted source and review its permissions.

Build and install

The source application lives in Frontend/. QML files define the interface, while main.py owns the WebEngine profiles, privacy interceptor, session settings, and downloads. The Feather icon pack is declared in requirements.txt.

The Linux package is built as an amd64 Debian package for Ubuntu 24.04/Linux Mint 22-compatible systems. It installs the app under /opt/quantum-browser and adds a desktop launcher.

Compatibility notes

  • Websites can change their layout or scripts at any time; website console warnings do not necessarily indicate a browser failure.
  • Some sites reject embedded browsers, require DRM, or rely on codecs unavailable in the QtWebEngine build.
  • Certificate overrides are per connection and are not a way to make an invalid certificate trustworthy.
  • The bundled Debian package is self-contained and substantially larger than the source project because it includes Qt and Chromium.
